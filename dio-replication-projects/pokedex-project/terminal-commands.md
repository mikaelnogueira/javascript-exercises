### Navigate to the Pokedex project directory from the repository root.

`cd .\dio-replication-projects\pokedex-project`

### Display the current directory.

`pwd`

### List the files and folders in the current directory.

`dir`

### Go back to the parent directory.

`cd ..`

### Clear the terminal screen in PowerShell.

`cls`

### Create an index.html file in PowerShell.

`New-Item -Name "index.html" -ItemType File`

### Short PowerShell command to create an index.html file.

`ni index.html -ItemType File`

### Create an index.html file when using Git Bash.

`touch index.html`

### Start a local server with http-server in PowerShell.

`http-server`
